ownCloud + MinIO S3 Self-Hosted Stack on Docker & Kubernetes

Docker Kubernetes ownCloud MinIO Nginx S3 API

This project deployed a full self-hosted ownCloud instance backed by MinIO S3-compatible object storage, first on Docker Compose and later migrated to Kubernetes, currently running with 2TB of storage on the S3 backend.

2TBStorage
S3Backend
K8sOrchestrated

Challenges

ownCloud's Docker entrypoint rewrites config.php on every container restart, which conflicts with any manual configuration for S3 storage. I worked around this with a persistent override strategy rather than editing the generated config directly. The files_primary_s3 app also had an incomplete vendor directory, requiring manual dependency resolution for missing GuzzleHttp/PSR-7 classes, plus cleanup of duplicate config key conflicts that surfaced during the migration to Kubernetes.

Result

The stack now runs live on the k3s cluster, with MinIO handling all object storage behind ownCloud's file layer, fronted by Nginx.
