INC-2025-002 · MALWARE · RESOLVED

WordPress OPcache-Disguised Webshell Remediation

WordPress PHP OPcache Malware Forensics ClamAV CSF

Across three WordPress sites, a sophisticated PHP webshell had been planted disguised as a legitimate OPcache file — placed deep enough in the WordPress filesystem to avoid casual inspection, and named to blend in with normal cache artifacts.

Method

The initial access vector was a file upload bypass, allowing the attacker to drop executable PHP where it shouldn't have been reachable. From there, the disguised webshell gave persistent remote access.

3Sites
6hAnalysis
0Downtime

Remediation

I ran a full filesystem audit across all three sites using ClamAV signatures combined with manual review, since disguised webshells like this one often evade generic scanners. Every persistent backdoor was removed, upload restrictions were tightened, and file permissions were hardened to prevent re-exploitation — all with zero downtime to the live sites.
