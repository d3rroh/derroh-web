Zero-Loss IMAP Migration: Zoho Mail → cPanel via imapsync

This migration moved a full mailbox from Zoho Mail to a cPanel Dovecot mail server using imapsync, with the goal of zero message loss and minimal disruption to the end user.

Process

Every folder was migrated with message flags (read/unread, flagged, etc.) preserved intact. I validated message counts before and after the sync to confirm nothing was dropped, then coordinated a live DNS MX cutover timed so the end user experienced no interruption to incoming mail during the switch.
