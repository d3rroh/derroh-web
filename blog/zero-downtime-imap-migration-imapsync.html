Zero-Downtime IMAP Migration with imapsync

imapsync email dovecot dns

imapsync is the tool of choice for mailbox migrations where zero message loss is non-negotiable — and getting a fully clean migration means treating folder mapping, flag preservation, and MX cutover timing as separate, deliberate steps rather than a single sync-and-hope operation.

Folder Mapping & Flags

Source and destination folder structures rarely match exactly out of the box, so mapping needs to be explicit rather than assumed. Message flags — read/unread, flagged, replied — need to survive the sync too, or the user opens their new inbox to a pile of everything marked unread.

Validation

Before calling a migration complete, I always run a pre/post message count comparison per folder. Any mismatch gets investigated before cutover, not after.

The MX Cutover

Once the migration is validated, the DNS MX cutover is the moment that actually matters to the end user. Timing it right — after a final delta sync to catch anything that arrived during migration — is what makes the whole process invisible to them.
